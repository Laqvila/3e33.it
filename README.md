# 3e33.it

Sito dell'**Associazione Culturale per i Centri Storici "Tre e Trentatré" (Associazione 3:33)**, L'Aquila.

Sito statico pubblicato con GitHub Pages: sostituisce il precedente sito WordPress ospitato su Aruba,
con gli stessi contenuti e gli stessi indirizzi delle pagine (`/masterclass-2025/`, `/2025/03/16/...`,
`/wp-content/uploads/...`), così i link già in circolazione continuano a funzionare.

- Nessun cookie, nessun servizio di terze parti caricato senza consenso: video YouTube e post Facebook
  si caricano solo quando il visitatore li richiede.
- Font ospitati sul sito, Content Security Policy restrittiva.

Questa cartella contiene solo il risultato generato: i sorgenti (contenuti modificabili e generatore `build.py`)
sono tenuti a parte, nella cartella di lavoro locale `_source/`.
